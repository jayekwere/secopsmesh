# Release notes

## 0.1.0 — Initial validated implementation

- Canonical versioned findings and bounded adapters across Wazuh/on-premises, AWS, Azure, GCP and Kubernetes.
- Durable evidence, explicit identity relationships, quality/conflict indicators, detection-as-code and replay.
- Cited deterministic investigation and restricted read-only MCP; optional Claude advisory boundary disabled by default.
- Independent role separation, signed exact-plan approval, durable claims, read-only ambiguity recovery, verified containment and authorized rollback.
- React operations console using real APIs, with browser-tested investigation and response flows.
- PostgreSQL/Compose deployment, disposable Cilium acceptance, security CI and reproducible reports/screenshots.

Provider contracts and synthetic demonstrations are distinguished from live acceptance. External cloud/Wazuh/Claude credentials were not supplied. Production hardening, identity lifecycle, migrations and operational limits are described in [validation](docs/VALIDATION.md).
